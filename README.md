# 🌐 WebSite Project

A modern, responsive, and collaborative front-end project built with HTML, CSS, and JavaScript.
Designed to showcase clean UI, accessibility, and teamwork in web design and development.

👉 Live Demo: [view Website](https://baumeistergroup3.netlify.app/)

🧭 Overview

This project represents a peer-designed website that highlights creativity, responsive layout, and user-friendly design.
It was created to demonstrate:

## 🧱 Semantic HTML structure

🎨 Reusable CSS components

⚙️ Smooth JavaScript interactions

🤝 Team collaboration using GitHub

🧰 Tech Stack

| Technology              | Purpose                            |
| ----------------------- | ---------------------------------- |
| 🧾 **HTML5**            | Semantic and accessible structure  |
| 🎨 **CSS3**             | Styling and responsive layout      |
| ⚙️ **JavaScript (ES6)** | DOM manipulation and interactivity |
| 🧭 **Git & GitHub**     | Version control and collaboration  |

## 💻 Project Design

Our design focuses on:

✨ Simplicity: Minimalist and modern layout

📱 Responsiveness: Adapts perfectly to all devices (mobile, tablet, desktop)

🧩 Reusability: Modular CSS and JS components

🧠 Accessibility: Semantic tags and ARIA-friendly design

🎯 Consistency: Unified color palette and typography system

The layout was planned in Figma and implemented following a component-based structure.

🧪 Testing Checklist

Before submitting your PR, ensure that:

The site looks good on mobile, tablet, and desktop

No broken links or images

HTML passes W3C validation

No console errors in browser

CSS and JS are properly linked
